A Minecraft launcher
built to be easy, fast, simple,
and lightweight.

Zero Launcher strips away the bloat of a typical launcher. It's a fast, open-source app for Windows and Linux that stays light on your system, so more of your CPU and RAM go to the game instead of the launcher. Swap loaders, tune instances, and reshape the interface itself — all running on a native Rust core instead of an Electron shell.

This project is still in beta — bugs are expected while things stabilize.

Performance is currently best on Windows, since Windows WebView2 is more optimized than Linux's WebKitGTK right now. That gap should close as the Linux build matures. Skeptical of a random launcher binary? Fair — run it through VirusTotal yourself, or just skip it, no hard feelings.

Under the hood

Everything a launcher should do, none of the bloat.

Zero Launcher trades an Electron shell for a native Rust core, and spends the savings on features you'll actually use.

Every major loader

Vanilla, Fabric, Forge, NeoForge, and Quilt are all supported out of the box — pick one per instance, no separate tools required.

Custom instances & presets

Save a full setup — loader, mods, memory, Java version — as a preset, then spin up new instances from it in seconds.

Built-in mod discovery

Browse and install mods without leaving the launcher, then manage them per-instance from one place.

Play & download modpacks

Browse and install modpacks straight from CurseForge and Modrinth, or import your own — .mrpack and .zip files are all supported.

Skin & cape management

Switch between saved skins and capes right from the launcher, and swap your active look before you hit play.

Microsoft or offline accounts

Sign in with a Microsoft account via device code, or play offline with a free local account — your call.

Automatic Java management

Zero Launcher detects and fetches the right Java runtime per instance, so version mismatches stop being your problem.

Discord Rich Presence

Show what you're playing — instance, version, and loader — right in your Discord status while you launch.

Crash analysis

When something breaks, the launcher reads the crash log and points you toward what actually went wrong.

A UI you can reshape

Custom backgrounds, accent colors, and layout touches — the "customizable" in the name is meant literally.
